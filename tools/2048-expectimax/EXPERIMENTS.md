# 实验数据与验收状态

更新时间：2026-10-05 06:07 UTC。当前报告是开发阶段记录，后续完整高预算实验仍在运行。

## 当前结论

**尚未证明本 JavaScript 求解器合成 32768 的总体概率 ≥ 1/3。** 低预算试跑已经出现明确失败，高预算不能因为“用了 Expectimax”而自动视为达标。尚未实施 N-tuple / TD 训练，也没有把不存在的训练或测量写成成果。

## 规则与统计口径

- 标准 4×4 棋盘，两次独立初始生成。
- 每次合法移动后，均匀选择空格，90% 生成 2，10% 生成 4。
- 第一次合成 32768 即记成功；不要求继续打到终局。
- 无合法移动记失败；安全上限 100,000 次有效移动被触发则记 `censored`，不是普通失败，也不冒充成功。
- 每局使用独立预定 uint32 种子和 Mulberry32；同一版本与节点预算下可复现决策轨迹。
- 报告所有局，不剔除慢局、坏种子或失败局。
- 95% 区间为双侧 Wilson 区间。样本内 ≥1/3 不等于置信下界 ≥1/3，更不等于证明总体概率精确是多少。

## 运行环境

- 可见 CPU 型号：INTEL(R) XEON(R) PLATINUM 8573C

- 这是共享/虚拟化运行环境；墙钟耗时会受其他任务影响，不能作为专用硬件性能保证

- 每个原始 JSONL 首行记录命令参数、实际选项、规则、种子范围、运行时及被执行源码 SHA-256。发布时仅将命令中的可执行文件和脚本绝对路径规范为 `node` / `benchmark.js`，并保留 `commandPathRedaction` 标记；实验参数、结果与源码哈希未修改

## 正确性验证

命令：

```sh
node test-expectimax2048.js
```

当前结果：**15 组测试通过**。完整运行耗时见测试日志；具体日志见 `test-results.txt`。

覆盖：

1. 全部 65,536 个四格行的左右移动，共 131,072 个方向用例；公开数值实现与独立规则比较，packed 路径在目标前表示范围内比较。
2. 10,000 个随机棋盘 × 4 方向，共 40,000 个棋盘方向测试。
3. 不重复合并、正确得分、方向转置、uint32 有符号边界、16384+16384→32768、公开接口 65536+65536→131072。
4. 生成位置/数值分布、确定性 RNG、无输入修改与无效输入拒绝。
5. 已达目标、无合法动作、极小预算时仍返回合法动作。
6. 独立启发式公式与 1–3 层显式生成/最大值搜索 oracle，包含概率截断。
7. 禁用/小型/大型置换表的完成搜索结果一致性。
8. 负启发式下不应偏爱确定死局的回归测试。
9. 浏览器 UMD 导出和 Node ESM 默认导入。
10. 唯一合法根动作立即返回，节点数为 0，且保持输入不变。

发现并修复过的两个问题：非终局启发式可能为负，导致输局值 0 错误占优；`Math.log2` 在大整数附近的舍入使不合法输入通过。当前主文件都已修复。测试是算法正确性的证据，不是成功率证明。

## 最终评估计划

开发期根据正确性、节点效率和试跑速度选定配置后，冻结源码与参数，再使用之前未用于开发选择的种子集合。计划预先固定至少 30 局并全部跑完；不因前几局幸运或失败而提前终止统计。

- 候选独立种子范围：50001–50030，尚未开始，不宣称存在对应结果。
- 每局到首次 32768 或真实终局；若出现 censored，保留并明确标注，补充完整运行后再作达标判断。
- 报告 n、成功数、比例、Wilson 区间、最大块分布、耗时与所有逐局记录。
- 若仅点估计 ≥1/3，结论只能是“该样本点估计达到目标”；若区间下界仍低于 1/3，必须写明证据不足。
- 若合理预算下纯 Expectimax 仍未显示足够强度，再评估 N-tuple/TD 后备路线；届时需明确训练数据、训练成本、独立评估种子，不能用手工权重假称训练完成。
