# 预训练模型来源、格式与授权

本项目使用 Hung Guei 发布的 TDL2048+ 基线 N-tuple 网络。上游模型卡说明它们以 Optimistic Temporal Difference Learning 训练，并明确将代码和发布模型置于 MIT 授权下。本项目进行推理、校验和格式转换，**没有声称在这里重新训练了模型**。

- [固定版本模型卡与 MIT 授权](https://huggingface.co/moporgic/TDL2048/blob/0899be24f2f53d1199225960330e6742177af81d/README.md)
- 模型仓库固定版本：`0899be24f2f53d1199225960330e6742177af81d`
- [推理规则参考源码](https://github.com/moporgic/TDL2048/blob/a99f620aec0d30a75943a4c9646743f1f53b0197/2048.cpp)
- 原始代码许可证见 `LICENSE-TDL2048.md`；本适配器及模型授权声明见 `LICENSE`

转换后的 float32 数据 SHA-256：

- 4x6：`01cbe0f0cf523c75947e0c449520399068a4f4bab73ae0d894cabc95ffcfd629`
- 8x6：`4e9342fa525ae41d5268e294f396dd066822cd9df88076b864d35f356f3f3297`

原始模型是小端二进制：文件头版本 0，随后为表数。每张表使用旧格式标记 `0x80`，包含模式签名、float32 宽度、16^6 项数据，以及两份仅供训练的状态数组。转换器先验证整个原始文件的 SHA-256，再按固定表结构流式复制价值数据，跳过训练状态；不会把原始二进制当作可执行代码或 pickle 加载。

每张表有 16,777,216 个 float32。模式的第一个格子对应索引最低 4 位；每个模式共享八种 D4 对称变换，所有查表值求和，不取平均。8x6 的实际模式顺序为：012456、456789、012345、234569、01259a、345678、134567、01489a。

JavaScript 使用双精度加和；上游 C++ 的 numeric 是 float。因此这里验证的是独立参考下的索引、转换和数学搜索语义，不宣称与 C++ 每一步浮点值逐位相同。最终胜率以本 JavaScript 实测为准，不能移用上游其他检查点的历史成绩。

上游标准 tile-downgrading 在首次达到 32768 后才触发。本任务在首次 32768 停止，所以未加入这项与目标无关的处理。

权重不进入 Git。运行 `prepare-model.js` 时才会显式下载；下载和转换后的文件放在已忽略的 models/ 目录中。转换/加载均核验大小与哈希。
